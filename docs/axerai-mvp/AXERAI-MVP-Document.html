1Executive Overview

Axerai transforms physical product packaging into an intelligent, conversational digital touchpoint — without requiring a native mobile application.

What it is

AI-Native Packaging OS (MVP)

Consumer scans QR / image target on box → 3D persona anchors on product → natural voice conversation via Gemini + Inworld. Memory persists per product code across sessions.

What it is not

Not a static QR website

Not a chatbot widget. Not a brochure. The packaging becomes a living brand ambassador with memory, verification, and voice — patent-pending 3-layer architecture.

4Three-Layer Verification Architecture

Core logic: Layer A is the fast visibility engine — persona appears immediately when product is detected. Layers B and C run in the background and return true/false without blocking Stage 1 reveal. One verify cycle per session.
Layer A
FAST

Product Visibility Engine

Trigger: Physical product / image target visible in camera.
Action: Instantly reveal 3D persona on packaging anchor (Stage 1).
Output: Persona live · AR session active.

Layer B
BG

Product Code / Brand Verification

Trigger: After Layer A — background Gemini vision on captured frame.
Action: Verifies brand text / product code (e.g. AXE-327T5).
Output: true = authentic · false = wrong/missing.

Layer C
BG

Liveness / Anti-Spoof

Trigger: Parallel with Layer B — background.
Action: Detects real product vs photo-on-screen, monitor replay, printed spoof.
Output: true = live product · false = spoof detected.

Verification Timing — Layer A First, B+C Background
