# Axerai Future — Real Market Sales × Scan Rate × Own TTS

## Core logic (tumhara point)

Axerai cost **sirf scan pe** lagta hai. Box pe “Powered by Axerai” → scan rate website se **zyada** (5–10%+).

**Example:**
- 100 Nike shoes sold @ ₹15,000
- Budget feeling ₹10/scan max
- **10% scan** = 10 scans → cost **₹100**
- **Per box sold** = ₹100 ÷ 100 = **₹1 / box**

Formula: **₹ per box = scan_rate × ₹ per scan**

| Scan rate | ₹2 / scan | ₹5 / scan | ₹10 / scan |
|--|--|--|--|
| 5% | ₹0.10 / box | ₹0.25 / box | ₹0.50 / box |
| **10%** | **₹0.20 / box** | **₹0.50 / box** | **₹1 / box** |
| 15% | ₹0.30 / box | ₹0.75 / box | ₹1.50 / box |

## Founder takeaway
1. **Per box economics strong:** 10% scan × ₹5 = **₹0.50 / box** (₹10 scan → ₹1 / box).
2. **Full Nike worldwide** = **~150 GPUs** — too big day-1.
3. **10 brands × tagged SKU** = **~50 GPUs · ~₹25L/mo · ~₹6 Cr/yr** — real future target.
4. Brand ko sell: “₹15,000 shoe pe Axerai cost **~50 paise–₹1 / box**.”
